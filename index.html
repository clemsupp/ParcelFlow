Bienvenue
Ton objectif est de construire une machine où chaque objet déclenche le suivant jusqu'à atteindre la cible.

Comment jouer ?

Construis une réaction en chaîne. Les objets doivent physiquement se toucher ou interagir pour déclencher les suivants.

👆 Sélection

Touche un objet pour le sélectionner. Fais-le glisser pour le déplacer.

🧩 Construire

Choisis un objet dans la barre du bas puis touche l'endroit où tu veux le placer.

▶ Lancer

Quand ta machine est prête, appuie sur ▶. Les objets commencent alors à bouger.

📱 Gestes tablette

Un doigt : placer ou déplacer.
Deux doigts : déplacer la caméra.
Pincer : zoomer.
